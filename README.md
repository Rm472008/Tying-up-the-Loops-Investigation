<h2>About the Investigation</h2>

<p>
<b>Tying-up-the-Loops</b> investigates the formation, structure, and behaviour of
<b>closed level curves</b> arising from parametric relationships.
</p>

<p>
The investigation combines analytical mathematics with computational
visualisation to examine how changes in a parameter influence the geometry
and topology of level curves.
</p>
